# 안지은 AI·디지털 교육 강사 웹 이력서

GitHub Pages에서 별도 설치 없이 바로 구동되는 정적 웹사이트입니다.

## GitHub에 올리는 방법

1. GitHub에서 새 Repository를 만듭니다.
2. 이 폴더 안의 파일 5개를 모두 업로드합니다.
3. Repository의 **Settings → Pages**로 이동합니다.
4. **Build and deployment**에서 `Deploy from a branch`를 선택합니다.
5. Branch를 `main`, 폴더를 `/(root)`로 선택하고 **Save**를 누릅니다.
6. 잠시 후 표시되는 주소를 누르면 웹 이력서를 볼 수 있습니다.

## 내용 수정

- 경력·문구: `index.html`
- 색상·글꼴·화면 구성: `styles.css`
- 화면 등장 효과: `script.js`

개인정보 보호를 위해 전화번호, 생년월일, 상세 주소는 넣지 않았습니다. 이메일 주소는 공개되므로 원하지 않으면 `index.html`에서 `ieum_ai@daum.net`을 검색해 삭제하거나 바꾸세요.
